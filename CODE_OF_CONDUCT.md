# Code of conduct

Treat contributors with respect. Give feedback about the work, welcome differing experience levels and give others room to participate. Harassment, threats, discrimination and sharing someone else's private information without permission are unacceptable.

For conduct concerns, contact the repository maintainer through the public contact options on the [maintainer's GitHub profile](https://github.com/abhi0874). Share sensitive details privately. The maintainer will assess reports, limit disclosure where possible and may remove content or restrict participation to protect contributors. Report vulnerabilities through [the security policy](SECURITY.md).
